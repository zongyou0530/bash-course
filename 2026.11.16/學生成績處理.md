EXERCISE

用 while 語法撰寫一個 Bash Shell Script，建立一個簡單的學生數學成績輸入與統計系統。
程式開始後，持續要求使用者輸入學生學號與數學成績。每次只處理一位學生，處理完後再繼續輸入下一位學生。當使用者在學生學號欄輸入 `END` 時，程式停止輸入並顯示最後統計結果。
學生學號的第一個字母代表所屬科系：E 代表 Electrical Engineering，C 代表 Computer Science，M 代表 Mechanical Engineering。其他開頭皆視為非法學號。科系判斷必須使用 `case statement` 完成。
若學生學號不是 `END`，程式按著要求輸入數學成績。成績必須介於 0 到 100 之間。若成績小於 0 或大於 100，顯示 `Invalid score`，該筆資料不得列入統計，然後繼續輸入下一位學生。
合法成績依下列方式分類：
90 到 100 分為 A+
80 到 89 分為 A
70 到 79 分為 B
60 到 69 分為 C
低於 60 分為 F
成績等級必須使用 `case statement` 完成。
每輸入一位合法學生後，畫面需顯示該學生的學號、科系、成績與等級。
在所有資料輸入過程中，程式必須持續統計：
合法學生總人數、非法資料筆數、A+ 人數、A 人數、B 人數、C 人數、F 人數，以及目前最高分。
當使用者輸入 `END` 後，程式必須顯示完整統計結果，包括：
總合法學生人數、非法資料筆數、各等級人數、最高分，以及通過人數。
其中成績 60 分以上視為通過。
最後，程式必須依合法學生的通過比例判斷整體結果：
若通過人數大於等於合法學生總人數的一半，顯示：
`Class Status: PASS`
否則顯示：
`Class Status: NEED IMPROVEMENT`
若完全沒有任何合法學生資料，則顯示：
`No valid student data.`
本題必須使用 `while` 迴圈持續輸入學生資料，必須使用 `case` 判斷科系與成績等級，並搭配 `if / elif / else`、數字比較或字串比較完成、不得預先假設學生人數，也不得逐筆重複寫相同程式碼。不得使用 Python、C、awk、sed 或 grep 指令。

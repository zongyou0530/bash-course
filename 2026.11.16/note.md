# 程式碼詳解

## 一、整體運行邏輯

```
開始 → 初始化變數
        ↓
   ┌→ 讀學號
   │    ├ 是 END ───────────────→ 跳出迴圈
   │    ├ 開頭不是 E/C/M → 非法+1 → 回到迴圈開頭
   │    ↓
   │  讀成績
   │    ├ 不是純數字 / 太長 / 超出 0~100 → 非法+1 → 回到迴圈開頭
   │    ↓
   │  判斷等級、更新統計、顯示該生資料
   └────┘
        ↓
   顯示最終統計 → 判斷 PASS / NEED IMPROVEMENT
```

核心概念是**「關卡式過濾」**：每筆資料依序通過學號、純數字、長度、範圍四道關卡，任何一關失敗就 `continue` 跳回迴圈開頭。能走到最後的才是合法資料，才允許更新統計。

## 二、逐區塊解說

### 區塊 1：Shebang 與註解

```bash
#!/bin/bash
# grade.sh - 學生數學成績輸入與統計系統
```

| 語法 | 說明 |
|---|---|
| `#!/bin/bash` | Shebang，告訴系統用 `/bin/bash` 來執行這個檔案。必須在第一行。 |
| `# ...` | `#` 開頭的是註解，Bash 會忽略。 |

---

### 區塊 2：變數初始化

```bash
total=0        # 合法學生總人數
invalid=0      # 非法資料筆數
cntAplus=0
cntA=0
cntB=0
cntC=0
cntF=0
pass=0         # 通過人數
max=-1         # 目前最高分
```

| 重點 | 說明 |
|---|---|
| `變數=值` | 賦值時**等號兩側不能有空白**。寫成 `total = 0` 會被當成執行 `total` 這個指令而出錯。 |
| 取值用 `$變數` | 例如 `$total`。賦值時不加 `$`。 |
| Bash 變數預設是字串 | 要做數學運算時要用 `$(( ))`，後面會說明。 |
| `max=-1` | 初始值設成比任何合法成績（0~100）都小的數，這樣第一筆合法成績（即使是 0）也一定會大於它，成功更新最高分。若初始化為 0，雖然也能運作，但 `-1` 在語意上更明確「尚無資料」。 |

---

### 區塊 3：標題與 while 迴圈

```bash
echo "===== 學生數學成績系統 (學號輸入 END 結束) ====="

while true
do
    ...
done
```

| 語法 | 說明 |
|---|---|
| `echo "文字"` | 輸出文字並換行。 |
| `while 條件; do ... done` | 條件為真就重複執行。 |
| `true` | 內建指令，永遠回傳成功（0），所以 `while true` 是**無限迴圈**。 |

為什麼用無限迴圈？題目要求「不得預先假設學生人數」，我們不知道會輸入幾位，所以讓它一直跑，直到使用者輸入 `END` 時用 `break` 手動跳出。

---

### 區塊 4：讀取學號與結束判斷

```bash
read -p "請輸入學生學號: " id

if [ "$id" = "END" ]; then
    break
fi
```

| 語法 | 說明 |
|---|---|
| `read -p "提示" 變數` | `-p` 顯示提示字，並把使用者輸入存入變數 `id`。 |
| `[ ... ]` | 條件測試（等同 `test` 指令）。**括號內側兩邊要有空白**。 |
| `"$id"` | 變數加雙引號。若使用者直接按 Enter（空字串），不加引號會變成 `[ = "END" ]` 而語法錯誤。 |
| `=` | **字串**相等比較。 |
| `break` | 立刻跳出整個 `while` 迴圈，程式接著執行 `done` 之後的統計輸出。 |
| `if ... then ... fi` | `fi` 是 `if` 倒過來寫，代表結束。 |

`END` 比較是區分大小寫的，所以小寫 `end` 不會結束，會被當成非法學號。

### 區塊 5：用 case 判斷科系

```bash
case $id in
    E*) dept="Electrical Engineering" ;;
    C*) dept="Computer Science" ;;
    M*) dept="Mechanical Engineering" ;;
    *)
        echo "Invalid student ID"
        invalid=$((invalid + 1))
        continue
        ;;
esac
```

**case 語法結構**

```
case 要判斷的值 in
    模式1) 要執行的指令 ;;
    模式2) 要執行的指令 ;;
    *)     都不符合時執行 ;;
esac
```

| 語法 | 說明 |
|---|---|
| `E*)` | 萬用字元模式：以 `E` 開頭、後面任意字元（含無字元）。`*` 代表任意長度的任意字串。 |
| `;;` | 結束這個分支（相當於其他語言的 `break`）。 |
| `*)` | 預設分支，放最後，捕捉所有前面沒符合的情況。 |
| `esac` | `case` 倒過來寫，代表結束。 |
| `$((invalid + 1))` | **算術展開**，計算括號內的運算後回傳結果。 |
| `continue` | 跳過本輪剩下的程式，**直接回到 `while` 的下一輪**。 |

這裡有兩個值得注意的地方：

1. **`case` 的比對是區分大小寫的**，所以 `e101` 會落入 `*)`，被視為非法。
2. **空字串**（直接按 Enter）不符合 `E*`、`C*`、`M*` 任何一個，也會落入 `*)`。

`continue` 寫在 `case` 裡面，作用對象仍是外層的 `while`，因為 `case` 不是迴圈。

### 區塊 6：讀取成績並檢查是否為純數字

```bash
read -p "請輸入數學成績: " score

case $score in
    ""|*[!0-9]*)
        echo "Invalid score"
        invalid=$((invalid + 1))
        continue
        ;;
esac
```

這是整個程式最精巧的部分。題目禁止使用 `grep`、`awk`、`sed`，所以我們用 `case` 的萬用字元來驗證格式。

| 模式 | 意義 |
|---|---|
| `""` | 空字串（使用者直接按 Enter）。 |
| `\|` | 「或」，用來串接多個模式。 |
| `[0-9]` | 括號表示「一個字元，可以是 0~9 其中之一」。 |
| `[!0-9]` | 驚嘆號代表**反向**：一個字元，**不是**數字。 |
| `*[!0-9]*` | 任意字元 + 一個非數字 + 任意字元，也就是「**字串中含有至少一個非數字字元**」。 |

所以整個模式的意思是：「空字串，或是含有任何非數字字元」→ 非法。

各種輸入的結果：

| 輸入 | 為何被擋 |
|---|---|
| `abc` | 含字母 |
| `-5` | 含 `-` |
| `85.5` | 含 `.` |
| `+90` | 含 `+` |
| `9 9` | 含空白 |
| （空） | 符合 `""` |

通過這個 `case` 之後，`score` 保證是**只由數字 0~9 組成、且至少一位**的字串。因此後面做數字比較時不會報錯。

### 區塊 7：長度檢查與去除前導 0

```bash
if [ ${#score} -gt 3 ]; then
    echo "Invalid score"
    invalid=$((invalid + 1))
    continue
fi
score=$((10#$score))
```

| 語法 | 說明 |
|---|---|
| `${#score}` | 取得字串**長度**。`${#變數}` 是固定寫法。 |
| `-gt` | 數字比較「大於」（greater than）。 |
| `10#$score` | 強制以**十進位**解讀。 |

**為什麼需要長度檢查？** 如果有人輸入一個極長的數字（例如 30 位數），Bash 的整數運算會溢位，結果不可預測，可能變成負數而繞過範圍檢查。限制長度 ≤ 3 位可以避免這個問題。合法成績最長是 `100`，剛好 3 位。

**為什麼需要 `10#`？** Bash 的算術運算中，**以 0 開頭的數字會被當成八進位**。例如 `085` 中的 `8` 不是合法八進位數字，會直接報錯 `value too great for base`。`10#085` 明確指定用十進位，所以結果是 `85`。

這一行同時也把 `score` 從字串 `"085"` 正規化成數字 `85`，後面的 `case` 比對才會正確（否則 `085` 無法匹配 `8[0-9]`）。

副作用：`0100`（4 位）會被長度檢查擋下，視為非法。這是設計取捨，因為多餘的前導 0 被視為異常輸入。

### 區塊 8：範圍檢查

```bash
if [ "$score" -lt 0 ] || [ "$score" -gt 100 ]; then
    echo "Invalid score"
    invalid=$((invalid + 1))
    continue
fi
```

| 語法 | 說明 |
|---|---|
| `-lt` | 小於（less than） |
| `-gt` | 大於（greater than） |
| `\|\|` | 邏輯「或」：左邊為真就不看右邊；左邊為假才判斷右邊。 |

因為前面已經排除負號，`-lt 0` 其實不會成立，但保留它是為了完整對應題目「小於 0 或大於 100」的條件，也讓程式在邏輯上自成一體，不依賴前面的過濾。

**Bash 比較運算子對照**

| 數字比較 | 字串比較 | 意義 |
|---|---|---|
| `-eq` | `=` | 等於 |
| `-ne` | `!=` | 不等於 |
| `-lt` | | 小於 |
| `-le` | | 小於等於 |
| `-gt` | | 大於 |
| `-ge` | | 大於等於 |

**數字用 `-eq` 系列，字串用 `=`。** 混用會出錯，例如 `[ "10" \> "9" ]` 按字串比較會判斷 `"10"` 比較小。

### 區塊 9：用 case 判斷成績等級

```bash
case $score in
    9[0-9]|100) grade="A+"; cntAplus=$((cntAplus + 1)) ;;
    8[0-9])     grade="A";  cntA=$((cntA + 1)) ;;
    7[0-9])     grade="B";  cntB=$((cntB + 1)) ;;
    6[0-9])     grade="C";  cntC=$((cntC + 1)) ;;
    *)          grade="F";  cntF=$((cntF + 1)) ;;
esac
```

| 模式 | 匹配的分數 |
|---|---|
| `9[0-9]` | 90~99（9 後面接一個數字） |
| `100` | 100 |
| `8[0-9]` | 80~89 |
| `7[0-9]` | 70~79 |
| `6[0-9]` | 60~69 |
| `*` | 其餘（0~59） |

| 語法 | 說明 |
|---|---|
| `;` | 同一行分隔多個指令（`grade="A+"` 然後 `cntAplus=...`）。 |
| `;;` | 結束整個 `case` 分支。兩者不同，別搞混。 |

**執行順序是由上到下，找到第一個符合的就停。** 所以 `*` 一定要放最後。

這個 `case` 之所以能運作，前提是：

1. `score` 已確認是純數字。
2. `score` 已去除前導 0（`085` → `85`）。
3. `score` 已確認在 0~100 範圍內。

少了任何一項前提，等級判斷都可能出錯。例如 `5` 這個單位數會落入 `*`（F），這是正確的；但如果沒有範圍檢查，`150` 也會落入 `*` 被判為 F，那就錯了。

### 區塊 10：更新統計

```bash
total=$((total + 1))

if [ "$score" -ge 60 ]; then
    pass=$((pass + 1))
fi

if [ "$score" -gt "$max" ]; then
    max=$score
fi
```

| 語句 | 說明 |
|---|---|
| `total=$((total + 1))` | 合法人數 +1。能走到這裡代表資料一定合法。 |
| `-ge 60` | 大於等於 60 視為通過。 |
| `-gt "$max"` | 新成績比目前最高分高，就更新。這是經典的「**擂台法**」找最大值。 |

等級計數器（`cntAplus` 等）放在區塊 9 的 `case` 內更新，因為此處才知道成績屬於哪一級。

### 區塊 11：顯示單一學生結果

```bash
echo "學號: $id | 科系: $dept | 成績: $score | 等級: $grade"
echo "目前最高分: $max"
echo "-----------------------------------"
done
```

雙引號內的 `$變數` 會被展開成實際的值。最後的 `done` 結束 `while` 迴圈，程式回到區塊 4 開始下一輪。

### 區塊 12：最終統計輸出

```bash
echo
echo "========== 統計結果 =========="

if [ "$total" -eq 0 ]; then
    echo "No valid student data."
    echo "非法資料筆數: $invalid"
else
    echo "總合法學生人數: $total"
    ...
fi
```

| 語法 | 說明 |
|---|---|
| `echo`（沒有參數） | 輸出空白行。 |
| `if ... then ... else ... fi` | 二選一分支。 |
| `-eq 0` | 數字相等比較。 |

這裡先判斷 `total` 是否為 0。若沒有任何合法學生，只顯示 `No valid student data.`，避免後面出現「最高分: -1」這種不合理的數字，也避免後面通過比例的計算毫無意義。

### 區塊 13：整體通過判斷

```bash
if [ $((pass * 2)) -ge "$total" ]; then
    echo "Class Status: PASS"
else
    echo "Class Status: NEED IMPROVEMENT"
fi
```

題目條件是：**通過人數 ≥ 總人數的一半**。

直覺寫法是 `pass -ge $((total / 2))`，但 Bash 只有**整數除法**，會捨去小數：

| total | total/2（Bash） | 真正的一半 |
|---|---|---|
| 4 | 2 | 2 |
| 5 | **2** | **2.5** |

當 total = 5、pass = 2 時：
- 錯誤寫法：`2 >= 2` → PASS（但 2 其實不到 2.5）
- 正確寫法：`2*2 = 4 >= 5`？否 → NEED IMPROVEMENT

兩邊同乘 2，不等式不變，且完全避開除法：

```
pass >= total / 2   ⟺   pass × 2 >= total
```

## 四、常見錯誤與除錯

| 症狀 | 可能原因 |
|---|---|
| `[: missing ']'` | `[` 或 `]` 旁邊少了空白 |
| `unary operator expected` | 變數沒加雙引號，且值為空 |
| `value too great for base` | 沒用 `10#`，`08`、`09` 被當八進位 |
| `integer expression expected` | 用 `-gt` 比較非數字字串 |
| `bad interpreter` / `\r` 錯誤 | 檔案含 Windows 換行符，用 `nano` 重新輸入 |
| 迴圈不會結束 | 輸入 `end`（小寫）而非 `END` |

## 六、被老師問到時的重點回答

1. **為什麼用 `while true`？** 人數未知，用 `break` 在 `END` 時才離開。
2. **為什麼不合法資料用 `continue`？** 直接略過後續的統計更新，確保非法資料不進入統計。
3. **為什麼用 `*[!0-9]*` 驗證數字？** 不能用 grep，所以改用 `case` 的萬用字元達成相同效果。
4. **為什麼要 `10#`？** 避免 `08`、`09` 被誤判為八進位。
5. **為什麼用 `pass * 2 >= total`？** Bash 整數除法會捨去小數，乘法可以避開誤差。

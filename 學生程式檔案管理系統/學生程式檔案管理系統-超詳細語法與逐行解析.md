## 1. 今天使用的語法與字詞

### 1.1 Bash 基本結構

| 語法／符號 | 用途 | 例子 |
|---|---|---|
| `#!/bin/bash` | 指定使用 Bash 執行程式 | 第一行 |
| `#` | 註解，執行時會忽略 | `# 主選單` |
| 換行 | 分隔不同指令 | 一行一個指令 |
| `" "` | 雙引號，讓變數內容作為一個整體 | `"$fname"` |
| `$(...)` | 命令替換；本程式未使用 | `today=$(date)` |
| `\` | 跳脫字元；本程式未使用 | `echo "\$"` |

### 1.2 變數與輸入輸出

| 語法 | 用途 | 例子 |
|---|---|---|
| `name=value` | 設定變數，等號兩側不能有空格 | `score=90` |
| `$name` | 取得變數內容 | `echo "$score"` |
| `read` | 讀取使用者輸入 | `read score` |
| `read -r` | 讀取輸入，不把反斜線當跳脫符號處理 | `read -r fname` |
| `printf` | 按指定格式輸出文字 | `printf "請輸入： "` |
| `echo` | 輸出文字或變數 | `echo "file ok"` |
| `local` | 宣告函式內的區域變數 | `local fname` |

**注意：** Bash 設定變數時，等號左右不能加空格。

```bash
score=90       # 正確
score = 90     # 錯誤：Bash 會把 score 當成指令
```

### 1.3 條件判斷與檔案測試

| 語法 | 意思 |
|---|---|
| `if` | 如果條件成立 |
| `elif` | 否則如果另一個條件成立 |
| `else` | 以上條件都不成立 |
| `fi` | 結束 if |
| `[ 條件 ]` | 傳統 test 條件判斷寫法 |
| `[[ 條件 ]]` | Bash 的條件判斷語法，功能較完整 |
| `-e 檔案` | 檔案或路徑是否存在 |
| `-f 檔案` | 是否為一般檔案 |
| `-r 檔案` | 目前使用者是否有讀取權限 |
| `-gt` | 整數大於 |
| `!` | 邏輯否定，表示「不是／不成立」 |

### 1.4 case、函式與迴圈

| 語法 | 意思 |
|---|---|
| `function_name() {` | 定義函式的開頭 |
| `}` | 函式或程式區塊的結尾 |
| `case 變數 in` | 依照不同模式進行分類 |
| `)` | 一個 case 分支的模式結尾 |
| `;;` | 結束目前 case 分支 |
| `*)` | 預設分支，接住其他所有情況 |
| `while true; do` | 無限迴圈的開始 |
| `done` | 結束 while 迴圈 |
| `select` | 建立數字選單 |
| `break` | 跳出目前一層迴圈 |
| `break 2` | 跳出兩層迴圈 |
| `return` | 結束目前函式並返回呼叫處 |
| `exit` | 結束整個 Shell 程式 |

### 1.5 正規表示式與數值運算

| 語法 | 意思 |
|---|---|
| `=~` | 在 `[[ ]]` 中進行正規表示式比對 |
| `^[0-9]+$` | 整個字串只能由一個以上的數字組成 |
| `$((...))` | Bash 整數算術運算 |
| `10#數字` | 將數字明確指定為十進位，避免前導 0 被誤判為八進位 |

### 1.6 檔案輸出

| 符號 | 意思 |
|---|---|
| `>` | 將輸出寫入檔案，原內容會被覆蓋 |
| `>>` | 將輸出附加到檔案最後面，不會覆蓋舊資料 |
| `cat 檔案` | 顯示檔案內容 |
| `touch 檔案` | 建立空檔案；若檔案已存在，通常只更新修改時間 |
| `ls` | 列出目前資料夾的檔案 |
| `pwd` | 顯示目前所在資料夾 |

## 2. 先理解整支程式在做什麼

這支程式是一個文字選單系統，提供五種功能：

| 選單編號 | 功能 | 對應函式／動作 |
|---|---|---|
| 1 | check file | 檢查檔案是否存在、是否為一般檔案、是否可讀 |
| 2 | check department | 根據學號第一個英文字母判斷科系 |
| 3 | show grade | 根據數學成績顯示等第 |
| 4 | save result | 將學號、成績、程式檔名附加寫入 result |
| 5 | exit | 顯示 goodbye 並離開程式 |

### 程式流程圖（概念）

```text
程式開始
   |
設定選單項目
   |
顯示選單並等待輸入
   |
依照使用者選擇執行功能
   |
   +-- 1：檢查檔案
   +-- 2：判斷科系
   +-- 3：判斷成績
   +-- 4：儲存結果
   +-- 5：離開程式
   |
執行完 1～4 後回到選單
   |
選擇 5 或輸入結束（Ctrl+D）
   |
程式結束
```

**為什麼要把程式拆成函式？**

每個函式負責一件事，主選單只負責呼叫功能。這樣比較容易閱讀、測試，也比較容易修改。

## 3. 完整程式碼

以下是本篇解析的程式版本：

```bash
#!/bin/bash
# 學生程式檔案管理系統

PS3="請選擇功能 (輸入編號): "
options=("check file" "check department" "show grade" "save result" "exit")

# ---------- check file ----------
check_file() {
    local fname
    printf "請輸入程式檔案名稱: "
    read -r fname

    if [ ! -e "$fname" ]; then
        echo "file not found"
    elif [ ! -f "$fname" ]; then
        echo "not a regular file"
    elif [ ! -r "$fname" ]; then
        echo "not readable"
    else
        echo "file ok"
    fi
}

# ---------- check department ----------
check_department() {
    local sid
    printf "請輸入學生學號: "
    read -r sid

    case $sid in
        [eE]*) echo "electrical engineering" ;;
        [cC]*) echo "computer science" ;;
        [mM]*) echo "mechanical engineering" ;;
        *)     echo "invalid student id" ;;
    esac
}

# ---------- show grade ----------
show_grade() {
    local score
    printf "請輸入數學成績 (0-100): "
    read -r score

    # 必須是非負整數 (負數、小數、文字都視為 invalid score)
    if [[ ! $score =~ ^[0-9]+$ ]]; then
        echo "invalid score"
        return
    fi

    score=$((10#$score))        # 去掉前導 0，避免 "085" 被當成八進位

    if [ "$score" -gt 100 ]; then
        echo "invalid score"
        return
    fi

    case $score in
        100|9[0-9]) echo "a+" ;;
        8[0-9])     echo "a"  ;;
        7[0-9])     echo "b"  ;;
        6[0-9])     echo "c"  ;;
        *)          echo "f"  ;;
    esac
}

# ---------- save result ----------
save_result() {
    local sid score fname
    printf "請輸入學生學號: "
    read -r sid
    printf "請輸入數學成績: "
    read -r score
    printf "請輸入程式檔名: "
    read -r fname

    # >> 為附加寫入：result 不存在會自動建立，已存在則接在最後面
    echo "$sid $score $fname" >> result
    echo "result saved"
}

# ---------- 主選單 ----------
# bash 的 select 在選完後不會自動重印選單，
# 所以外面包一層 while，每次處理完就 break 讓 select 重新開始。
while true; do
    picked=0

    select choice in "${options[@]}"; do
        picked=1

        case $choice in
            "check file")        check_file ;;
            "check department")  check_department ;;
            "show grade")        show_grade ;;
            "save result")       save_result ;;
            "exit")
                echo "goodbye"
                break 2          # 同時跳出 select 與 while
                ;;
            *)
                echo "invalid selection"
                ;;
        esac

        break                    # 回到 while，重新顯示選單
    done

    # select 沒進入過迴圈本體 = 輸入結束 (Ctrl+D)，避免無窮迴圈
    if [ "$picked" -eq 0 ]; then
        echo
        echo "goodbye"
        break
    fi
done
```

## 4. 逐行解析

### 4.1 程式開頭與選單設定

```bash
#!/bin/bash
```

- `#!` 稱為 shebang。
- `/bin/bash` 指定使用 Bash 解讀這份程式。
- 這行通常放在 Shell 腳本第一行。

```bash
# 學生程式檔案管理系統
```

- `#` 後面是註解。
- 註解是給人看的，不會當成指令執行。

```bash
PS3="請選擇功能 (輸入編號): "
```

- `PS3` 是 Bash 的選單提示字串。
- 使用 `select` 時，Bash 會在選單前顯示這段文字。
- 等號左右不能加空格。
- 字串使用雙引號包住，保留空格與中文字元。

```bash
options=("check file" "check department" "show grade" "save result" "exit")
```

這行建立一個陣列，裡面有五個選項。

- `options`：陣列名稱。
- `=(...)`：將多個元素放進陣列。
- 每個選項用雙引號包住，因為部分選項有空格。
- 陣列索引從 0 開始，但 `select` 顯示給使用者的選單編號從 1 開始。

### 4.2 check_file：檢查檔案

```bash
check_file() {
```

- `check_file` 是函式名稱。
- `()` 表示函式。
- `{` 表示函式內容開始。
- 主選單呼叫 `check_file` 時，才會執行函式裡的指令。

```bash
    local fname
```

- 宣告區域變數 `fname`。
- `local` 讓變數只在這個函式的作用範圍內使用。
- `fname` 用來存放使用者輸入的檔名。

```bash
    printf "請輸入程式檔案名稱: "
    read -r fname
```

第一行顯示提示文字；第二行等待使用者輸入，並把輸入內容存入 `fname`。

例如輸入：

```text
test.sh
```

之後 `fname` 的內容就是 `test.sh`。

```bash
    if [ ! -e "$fname" ]; then
        echo "file not found"
```

逐個符號理解：

- `if`：開始條件判斷。
- `[` 與 `]`：test 條件判斷的邊界，左右需要空格。
- `-e "$fname"`：檢查這個路徑是否存在。
- `!`：反轉條件。
- `! -e`：不存在。
- `then`：條件成立後要執行的內容。
- `echo`：輸出結果。

所以這段的意思是：**如果檔案不存在，就顯示 file not found。**

```bash
    elif [ ! -f "$fname" ]; then
        echo "not a regular file"
```

- `elif` 是「否則如果」。
- `-f` 檢查路徑是否為一般檔案。
- `! -f` 表示不是一般檔案。
- 例如資料夾不是一般檔案，因此會進入這個分支。

```bash
    elif [ ! -r "$fname" ]; then
        echo "not readable"
```

- `-r` 檢查目前使用者是否有讀取權限。
- `! -r` 表示沒有讀取權限。

```bash
    else
        echo "file ok"
    fi
```

- 前面條件都不成立，代表檔案存在、是一般檔案，而且可讀。
- `else` 執行最後的預設情況。
- `fi` 是 `if` 的結束標記。

最後的 `}` 結束整個 `check_file` 函式。

**判斷順序很重要：** 先確認存在，再確認一般檔案，最後才確認讀取權限。若檔案不存在，就不需要繼續檢查它是不是一般檔案。

### 4.3 check_department：判斷科系

```bash
check_department() {
    local sid
    printf "請輸入學生學號: "
    read -r sid
```

- 定義 `check_department` 函式。
- `sid` 是 student ID（學生學號）的縮寫。
- `read -r sid` 把輸入的學號存入 `sid`。

接著：

```bash
    case $sid in
        [eE]*) echo "electrical engineering" ;;
        [cC]*) echo "computer science" ;;
        [mM]*) echo "mechanical engineering" ;;
        *)     echo "invalid student id" ;;
    esac
```

`case` 用來依照變數符合的模式，選擇要執行的分支。

- `case $sid in`：檢查 `sid` 的內容。
- `[eE]*`：第一個字元是小寫 e 或大寫 E，後面可以接任何內容。
- `[cC]*`：第一個字元是 c 或 C。
- `[mM]*`：第一個字元是 m 或 M。
- `*)`：以上都不符合時的預設分支。
- `;;`：結束該分支。
- `esac`：`case` 倒過來拼寫，代表 case 結束。

例如：

| 輸入學號 | 判斷結果 |
|---|---|
| `E123456` | electrical engineering |
| `e123456` | electrical engineering |
| `C123456` | computer science |
| `M123456` | mechanical engineering |
| `A123456` | invalid student id |

**注意：** 這段只檢查第一個字元是否符合科系代碼，並沒有檢查學號後面的字元是否全部為數字。

### 4.4 show_grade：判斷成績

```bash
show_grade() {
    local score
    printf "請輸入數學成績 (0-100): "
    read -r score
```

- 定義成績判斷函式。
- `score` 儲存使用者輸入的成績。
- 先讀取輸入，再進行格式驗證。

#### 第一步：確認輸入是不是非負整數

```bash
    if [[ ! $score =~ ^[0-9]+$ ]]; then
        echo "invalid score"
        return
    fi
```

這裡使用 `[[ ]]`，而不是單中括號 `[ ]`，因為要使用正規表示式運算子 `=~`。

正規表示式：

`^[0-9]+$`

拆解如下：

| 部分 | 意思 |
|---|---|
| `^` | 字串開頭 |
| `[0-9]` | 任一個 0 到 9 的數字 |
| `+` | 前面的數字至少出現一次 |
| `$` | 字串結尾 |

因此整個式子要求：**從頭到尾都只能是數字，而且至少有一位。**

| 輸入 | 是否符合 |
|---|---|
| `85` | 是 |
| `0` | 是 |
| `100` | 是 |
| `085` | 是 |
| `-5` | 否 |
| `85.5` | 否 |
| `abc` | 否 |
| 空白 | 否 |

`! $score =~ ...` 表示「不符合這個正規表示式」。

如果不符合：

1. 顯示 `invalid score`。
2. 執行 `return`，結束目前的 `show_grade` 函式。
3. 回到主選單繼續執行。

#### 第二步：處理前導 0

```bash
    score=$((10#$score))
```

- `$((...))` 是 Bash 的整數算術展開。
- `10#` 明確指定後面的數字使用十進位解讀。
- 這樣輸入 `085` 時，會正確得到十進位的 85。

這行的目的不是改變成績，而是避免前面有 0 時產生數字進位制解讀問題。

#### 第三步：確認成績沒有超過 100

```bash
    if [ "$score" -gt 100 ]; then
        echo "invalid score"
        return
    fi
```

- `-gt` 是 greater than，意思是大於。
- `"$score" -gt 100`：成績是否大於 100。
- 若大於 100，就顯示錯誤並結束函式。

前面已經確認輸入是非負整數，所以這裡只需要檢查是否超過 100。

#### 第四步：用 case 分類成績

```bash
    case $score in
        100|9[0-9]) echo "a+" ;;
        8[0-9])     echo "a"  ;;
        7[0-9])     echo "b"  ;;
        6[0-9])     echo "c"  ;;
        *)          echo "f"  ;;
    esac
```

這裡使用 Shell 的模式比對：

| 模式 | 代表的成績 | 輸出 |
|---|---:|---|
| `100|9[0-9]` | 90～100 | a+ |
| `8[0-9]` | 80～89 | a |
| `7[0-9]` | 70～79 | b |
| `6[0-9]` | 60～69 | c |
| `*` | 其他有效整數，即 0～59 | f |

拆解：

- `100|9[0-9]`：`|` 在這裡代表「或」；可以是 100，也可以是 90～99。
- `[0-9]`：任一個數字。
- `*`：符合任意字元序列的模式；在最後一個分支代表其他情況。
- `;;`：結束該分支。

### 4.5 save_result：儲存資料

```bash
save_result() {
    local sid score fname
```

- 定義儲存資料函式。
- 一次宣告三個區域變數：`sid`、`score`、`fname`。
- 分別存放學號、成績與程式檔名。

接下來三組輸入：

```bash
    printf "請輸入學生學號: "
    read -r sid
    printf "請輸入數學成績: "
    read -r score
    printf "請輸入程式檔名: "
    read -r fname
```

每組都是先顯示提示，再把使用者輸入存進指定變數。

最重要的是：

```bash
    echo "$sid $score $fname" >> result
```

假設輸入：

- 學號：`E123456`
- 成績：`85`
- 檔名：`main.sh`

這行會把以下內容寫入名為 `result` 的檔案：

```text
E123456 85 main.sh
```

**為什麼使用 `>>`？**

- 如果 `result` 不存在，Shell 會建立它。
- 如果 `result` 已存在，新資料會加在檔案最後面。
- 原本的內容不會被覆蓋。

最後：

```bash
    echo "result saved"
}
```

顯示儲存成功訊息，並用 `}` 結束函式。

### 4.6 主選單：select 與 while

主選單是整支程式的控制中心。

#### 外層 while

```bash
while true; do
    picked=0
```

- `while` 是迴圈。
- `true` 永遠回傳成功，因此形成無限迴圈。
- `do` 表示迴圈內容開始。
- `picked=0` 先把旗標設為 0，代表目前還沒有進入選單迴圈本體。

為什麼需要 while？因為這份程式希望每次執行完一項功能後，都重新顯示選單。

#### select 選單

```bash
    select choice in "${options[@]}"; do
        picked=1
```

- `select` 會根據陣列內容產生編號選單。
- `choice` 是用來接收使用者選到的選項文字。
- `in` 後面放選單項目。
- `"${options[@]}"` 代表展開陣列中的所有元素，並保留每個元素各自的邊界。
- 使用者選擇有效編號後，`choice` 會取得對應的文字。
- `picked=1` 表示已經進入 select 的迴圈本體。

例如選單可能顯示：

```text
1) check file
2) check department
3) show grade
4) save result
5) exit
請選擇功能 (輸入編號):
```

#### 根據選項執行功能

```bash
        case $choice in
            "check file")        check_file ;;
            "check department")  check_department ;;
            "show grade")        show_grade ;;
            "save result")       save_result ;;
            "exit")
                echo "goodbye"
                break 2
                ;;
            *)
                echo "invalid selection"
                ;;
        esac
```

這段會根據 `choice` 的內容執行對應函式：

- 選到 `check file`：呼叫 `check_file`。
- 選到 `check department`：呼叫 `check_department`。
- 選到 `show grade`：呼叫 `show_grade`。
- 選到 `save result`：呼叫 `save_result`。
- 選到 `exit`：顯示 `goodbye`，再跳出兩層迴圈。
- 其他情況：顯示 `invalid selection`。

**為什麼函式名稱後面沒有括號？**

在 Bash 中，定義函式時會寫成 `check_file() {`；呼叫函式時直接寫 `check_file` 即可。

#### break：回到選單

```bash
        break
    done
```

這個 `break` 沒有指定層數，因此只跳出目前的 `select` 迴圈。

接著程式回到外層 `while`，重新執行一次 `select`，因此選單會再次顯示。

#### 為什麼離開選單使用 break 2？

```bash
            "exit")
                echo "goodbye"
                break 2
                ;;
```

目前有兩層迴圈：

1. 外層：`while true`
2. 內層：`select choice ...`

- `break`：只跳出一層。
- `break 2`：同時跳出兩層。

因此選擇 exit 時，必須使用 `break 2`，才能離開整個選單系統。

#### 用 picked 判斷 Ctrl+D

```bash
    if [ "$picked" -eq 0 ]; then
        echo
        echo "goodbye"
        break
    fi
done
```

這段處理使用者輸入結束（例如在選單等待輸入時按 Ctrl+D）的情況。

- 一開始 `picked=0`。
- 如果 select 成功進入迴圈本體，就會改成 `picked=1`。
- 如果輸入結束，select 可能不會進入迴圈本體，`picked` 就會維持 0。
- `-eq` 是整數相等比較。
- 因此 `[ "$picked" -eq 0 ]` 成立時，就顯示 goodbye 並跳出外層 while。

最後的 `done` 結束 while 迴圈。

## 5. 容易混淆的語法比較

### 5.1 `[ ]` 與 `[[ ]]`

| 比較 | `[ ]` | `[[ ]]` |
|---|---|---|
| 名稱 | test 條件語法 | Bash 條件語法 |
| 檔案測試 | 可以 | 可以 |
| 整數比較 | 可以 | 可以 |
| 正規表示式 `=~` | 不支援 | 支援 |
| 本程式用途 | 檢查檔案、比較整數 | 驗證成績格式 |

記憶方式：**一般檔案與數值測試可以用 `[ ]`；需要 Bash 正規表示式比對時用 `[[ ]]`。**

### 5.2 `>` 與 `>>`

| 符號 | 功能 | 結果 |
|---|---|---|
| `>` | 覆蓋寫入 | 舊內容會被取代 |
| `>>` | 附加寫入 | 新內容接在舊內容後面 |

例如：

```bash
echo "第一筆" > result
echo "第二筆" >> result
```

最後 `result` 內容：

```text
第一筆
第二筆
```

如果第二行也使用 `>`，第一筆資料就會被覆蓋。

### 5.3 break、break 2、return、exit

| 指令 | 功能 | 影響範圍 |
|---|---|---|
| `break` | 跳出迴圈 | 一層迴圈 |
| `break 2` | 跳出迴圈 | 兩層迴圈 |
| `return` | 結束函式 | 目前函式 |
| `exit` | 結束 Shell 程式 | 整個程式 |

這支程式的使用方式：

- 功能執行完後：用 `break` 離開 select，回到 while。
- 選擇 exit：用 `break 2` 離開 select 與 while。
- 成績格式錯誤：用 `return` 結束 show_grade。
- `exit` 並沒有用在這支程式中。

### 5.4 Shell 模式與正規表示式不是同一種東西

本程式同時使用兩種比對方式：

**case 的 Shell 模式：**

```bash
[eE]*
```

表示第一個字元是 e 或 E，後面可以接任意字元序列。

**[[ ]] 的正規表示式：**

```bash
^[0-9]+$
```

表示整個字串只能由數字組成。

不要把兩種規則混為一談：`case` 使用 Shell pattern；`[[ ... =~ ... ]]` 使用正規表示式。

### 5.5 為什麼變數常常要加雙引號？

例如：

```bash
[ ! -e "$fname" ]
```

使用雙引號能讓變數內容保持為一個整體。

假設使用者輸入：

```text
my program.sh
```

若沒有適當引用，空格可能讓 Shell 把它拆成多個部分。初學階段可養成習慣：**一般使用變數時，優先寫成 `"$變數"`。**

例外是本程式中的 `[[ ! $score =~ ^[0-9]+$ ]]`，正規表示式右側需要作為模式使用，這裡不要把整個模式當成普通字串隨意加引號。

## 7. 考前重點整理

1. **函式定義：** `function_name() { ... }`；呼叫函式時直接寫函式名稱。
2. **區域變數：** 在函式內使用 `local`。
3. **讀取輸入：** `read -r 變數`。
4. **if 結構：** `if ...; then ... elif ...; then ... else ... fi`。
5. **檔案測試：** `-e` 存在、`-f` 一般檔案、`-r` 可讀。
6. **case 結構：** `case 變數 in ... ;; esac`。
7. **預設分支：** `*)`。
8. **正規表示式：** `[[ 變數 =~ ^[0-9]+$ ]]` 可檢查是否為非負整數。
9. **整數比較：** `-gt` 大於、`-eq` 相等。
10. **算術展開：** `$((...))`。
11. **select：** 自動建立數字選單；`PS3` 控制提示文字。
12. **陣列展開：** `"${options[@]}"` 保留每個陣列元素。
13. **迴圈：** `while ...; do ... done`。
14. **跳出控制：** `break` 跳一層、`break 2` 跳兩層、`return` 結束函式。
15. **檔案輸出：** `>` 覆蓋、`>>` 附加。

### 常見錯誤

- 變數設定等號兩側不能有空格。
- `[ ]` 內側需要空格，例如 `[ "$x" -eq 1 ]`。
- `if` 要用 `fi` 結束。
- `case` 要用 `esac` 結束。
- `while`、`select` 要用 `done` 結束。
- 每個 case 分支通常用 `;;` 結束。
- 變數含空格時，通常要用雙引號包住。
- `>` 會覆蓋檔案，`>>` 才是附加資料。
- `break` 不等於 `return`，也不等於 `exit`。

## 學習建議

第一次讀這份程式時，不必一次背下所有語法。建議依照以下順序練習：

1. 先看懂 `read`、變數與 `echo`。
2. 再練習 `if`、`[ ]` 與檔案測試。
3. 接著理解 `case` 和模式比對。
4. 再看函式如何把功能拆開。
5. 最後理解 `select`、`while` 與 `break 2` 的控制流程。

**最重要的學習方式：** 不只是知道每一行的意思，也要能預測輸入某個資料後，程式會走到哪一個分支，以及為什麼會得到那個輸出。

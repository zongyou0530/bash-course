

# Bash 學生資料與成績檢查程式：詳細解說

## 1. 程式用途與執行流程

這支 Bash 腳本會依序：

1. 詢問學生學號，並拒絕空白學號。
2. 詢問數學成績及程式檔名。
3. 根據學號第一個字元判斷科系。
4. 確認成績是 `0` 到 `100` 的整數。
5. 將成績前面的 `0` 去掉，再判斷分數範圍。
6. 根據成績決定等級與評語。
7. 確認程式檔名符合「學號加上小寫 `.sh`」的規則。
8. 確認該檔案存在、是普通檔案，而且可以讀取。
9. 選擇輸出檔案名稱。
10. 將整理好的學生資料顯示在畫面上，並附加寫入輸出檔案。

整體流程可以簡化為：

```text
輸入資料
  ↓
檢查學號
  ↓
依學號判斷科系
  ↓
驗證並整理成績
  ↓
判斷成績等級
  ↓
驗證程式檔名與檔案
  ↓
選擇輸出檔名
  ↓
輸出至畫面和檔案
```

如果程式在任何一項檢查中遇到錯誤，就會顯示錯誤訊息，並以非零狀態碼結束。

---

## 2. Bash、Shell 與腳本是什麼？

### Shell

Shell 是使用者與作業系統之間的命令介面。使用者可以透過 Shell 輸入命令，讓作業系統執行程式、讀取檔案或處理資料。

### Bash

Bash 是一種常見的 Shell，全名為 **Bourne Again SHell**。這支程式使用 Bash 語法，所以不能假設每一種 Shell 都能完整支援它。

### Shell 腳本

Shell 腳本（shell script）是把多個 Shell 命令寫進文字檔，讓 Shell 依序執行。這支程式就是一個 Bash 腳本。

---

## 3. 第一行：指定直譯器

```bash
#!/bin/bash
```

這一行叫做 **shebang**，通常用來告訴作業系統，應該使用哪個程式執行這個腳本。

- `#!` 是特殊標記。
- `/bin/bash` 是 Bash 程式的路徑。
- 當腳本以可執行檔方式啟動時，系統會依這一行找到 Bash。

例如，在 Linux 或 macOS 上，若檔名為 `check_grade.sh`，可先賦予執行權限：

```bash
chmod +x check_grade.sh
```

再用以下方式執行：

```bash
./check_grade.sh
```

也可以直接把檔案交給 Bash 執行：

```bash
bash check_grade.sh
```

這種執行方式通常不需要先把腳本設為可執行。

> `/bin/bash` 必須是系統上 Bash 的實際安裝路徑。不同環境的路徑可能不同。

## 4. 讀取使用者輸入

```bash
read -r -p "請輸入學生學號: " id
```

### `read`

`read` 是 Bash 內建命令，用來從標準輸入讀取一行文字。通常是等待使用者在終端機輸入資料，按 Enter 後再繼續。

### `-p`

`-p` 會先顯示提示文字，再等待輸入：

```bash
-p "請輸入學生學號: "
```

提示文字顯示在終端機上，但不會自動加入變數內容。

### `-r`

`-r` 代表不把反斜線 `\` 當成跳脫字元處理。加上 `-r` 可以讓輸入內容較忠實地保留。

### `id`

`id` 是接收輸入的變數名稱。使用者輸入後，文字會被存進這個變數。

這行也可以用概念上的形式理解：

```text
顯示提示 → 等待輸入 → 將輸入內容存入 id
```

接著程式連續讀取兩項資料：

```bash
read -r -p "請輸入數學成績: " score
read -r -p "請輸入程式檔案名稱: " filename
```

- `score` 儲存使用者輸入的成績。
- `filename` 儲存使用者輸入的程式檔案名稱。

## 5. 學號不可為空

```bash
if [ -z "$id" ]; then
    echo "錯誤：學號不得為空字串！"
    exit 1
fi
```

### `if ... then ... fi`

這是 Bash 的條件判斷結構：

```bash
if 條件; then
    條件成立時執行的命令
fi
```

如果條件成立，便執行 `then` 和 `fi` 之間的內容。

### `[ ... ]`

`[` 是 Bash 常見的條件測試命令，也可以理解成 `test` 命令的一種寫法。它本身是一個命令，所以左右兩側必須保留空格：

```bash
[ -z "$id" ]
```

這些空格不可任意省略。

### `-z`

`-z` 用來檢查字串長度是否為零：

- 字串是空的：條件成立。
- 字串包含一個以上字元：條件不成立。

所以：

```bash
[ -z "$id" ]
```

就是「檢查 `id` 是否為空字串」。

### `"$id"`

變數前加 `$` 表示取出變數的值。雙引號可保護包含空格或特殊字元的內容，避免 Shell 將內容拆成多個參數或誤作其他語法。

例如，若變數包含 `A B`：

- 未加雙引號時，某些命令可能把它視為兩個項目。
- 加上雙引號後，則作為同一個字串處理。

### `echo`

`echo` 將文字顯示在終端機。

### `exit 1`

`exit` 會結束目前腳本。後面的數字是結束狀態碼：

- `0` 通常表示成功。
- 非 `0` 通常表示發生錯誤。
- 此處使用 `1` 表示學號空白造成程式中止。

腳本結束後，其他程式或 Shell 也可以依這個狀態碼判斷執行結果。

## 6. 由學號第一個字元判斷科系

```bash
first_char="${id:0:1}"
```

這是 Bash 的**字串切片**語法。

一般形式為：

```bash
${變數:起始位置:取出的字元數}
```

這裡的：

```bash
${id:0:1}
```

意思是：

- 從 `id` 的位置 `0` 開始。
- 取出 `1` 個字元。

Bash 字串位置從 `0` 開始，因此這會取得學號第一個字元，並將結果存入 `first_char`。

接著使用 `case`：

```bash
case "$first_char" in
    E)
        dept="ELECTRICAL ENGINEERING"
        ;;
    C)
        dept="COMPUTER SCIENCE"
        ;;
    M)
        dept="MECHANICAL ENGINEERING"
        ;;
    *)
        echo "錯誤：非法的學號！"
        exit 1
        ;;
esac
```

### `case ... in`

`case` 用來將一個值與多個模式逐一比對，適合處理多個選項。

基本結構如下：

```bash
case "$變數" in
    模式一)
        命令
        ;;
    模式二)
        命令
        ;;
    *)
        預設處理
        ;;
esac
```

### 各模式的意思

- `E)`：如果第一個字元符合 `E`，設定科系為 `ELECTRICAL ENGINEERING`。
- `C)`：如果第一個字元符合 `C`，設定科系為 `COMPUTER SCIENCE`。
- `M)`：如果第一個字元符合 `M`，設定科系為 `MECHANICAL ENGINEERING`。
- `*)`：萬用預設模式，表示前面的模式都不符合。

每個分支最後的 `;;` 表示該分支結束，不再繼續檢查下一個模式。整個 `case` 結構以 `esac` 結束；`esac` 是 `case` 倒過來寫。

### 科系判斷的限制

此程式只依學號的第一個字元判斷，而且只接受大寫 `E`、`C`、`M`：

- `E12345`：接受。
- `C12345`：接受。
- `M12345`：接受。
- `e12345`：拒絕，因為小寫 `e` 不等於大寫 `E`。
- 空字串在前面的檢查已被拒絕。
- 以其他字元開頭的學號會進入 `*` 分支並結束程式。

這裡沒有進一步檢查學號其餘部分是否為數字，或是否符合特定長度。

## 7. 確認成績為非負整數

```bash
case "$score" in
    ''|*[!0-9]*)
        echo "錯誤：成績必須是 0 到 100 之間的整數！"
        exit 1
        ;;
esac
```

這段 `case` 用來排除空字串，以及含有非數字字元的輸入。

### `''`

兩個單引號中間沒有字元，代表空字串模式。

### `|`

在 `case` 模式中，直線符號 `|` 表示「或」。所以：

```bash
''|*[!0-9]*
```

表示符合以下任一模式：

1. 空字串。
2. 包含至少一個非數字字元的字串。

### `*`

在這種模式比對中，`*` 可以匹配零個或多個任意字元。

### `[!0-9]`

這是字元集合：

- `0-9` 表示數字 `0` 到 `9`。
- 前面的 `!` 表示「不屬於集合中的字元」。

所以 `[!0-9]` 表示任一個非數字字元。

### `*[!0-9]*`

這個模式的意思是：

> 字串中某處至少出現一個非數字字元，前後可以有任意文字。

例如以下輸入會被拒絕：

- `abc`
- `80分`
- `-1`
- `10.5`
- ` 80`
- `+80`

只有由數字 `0` 到 `9` 組成的非空字串，才會通過這一層檢查。

此處錯誤訊息說明成績必須是 `0` 到 `100`，但這個 `case` 本身只檢查「非空、全部為數字」。真正的上限檢查在後面的程式完成。

## 8. 去除成績前面的零

```bash
score_num="${score#"${score%%[!0]*}"}"
```

這是一行較進階的 Bash 參數展開，目的是移除成績開頭的零。

### 為什麼要去除前導零？

在某些 Shell 數值運算情境中，前導零可能造成數字被當成八進位形式解讀。例如，`010` 可能被解讀成八進位，而不一定依使用者預期當成十進位 `10`。

這支程式沒有用算術運算來去零，而是用字串處理，讓後續數值比較使用較標準的十進位字串。

### 內層：`${score%%[!0]*}`

`%` 和 `%%` 是從字串右側移除符合模式的部分：

- `%` 移除最短匹配。
- `%%` 移除最長匹配。

此處模式是：

```bash
[!0]*
```

也就是「一個不是 `0` 的字元，後面再接任意內容」。

`%%` 會盡可能移除符合模式的最長後綴，留下分數開頭連續的零。

例如：

| `score` | `${score%%[!0]*}` 的結果 |
|---|---|
| `00042` | `000` |
| `007` | `00` |
| `100` | 空字串 |
| `000` | `000` |

### 外層：`${score#...}`

`#` 從字串左側移除符合模式的**最短前綴**。

因此：

```bash
${score#"${score%%[!0]*}"}
```

會從原始成績字串中移除前面連續的零。

例如：

```text
原始 score：00042
移除前綴：000
結果 score_num：42
```

對於 `100`，內層結果是空字串，外層不會移除內容，所以 `score_num` 仍是 `100`。

## 9. 將全零成績設為數字 `0`

```bash
if [ -z "$score_num" ]; then
    score_num=0
fi
```

若原始成績只包含零，前一段的處理可能會得到空字串：

```text
輸入：000
處理結果：空字串
```

此處再將空字串改成 `0`，使後續輸出顯示為一致的形式。

```bash
score_num=0
```

這是變數指定。賦值時 `=` 左右不能加空格：

```bash
score_num=0
```

以下形式在 Bash 中不是同一種合法賦值寫法：

```bash
score_num = 0
```

## 10. 檢查成績不得超過 100

```bash
if [ "${#score_num}" -gt 3 ] || [ "$score_num" -gt 100 ]; then
    echo "錯誤：成績必須介於 0 到 100 之間！"
    exit 1
fi
```

### `${#score_num}`

這種參數展開會取得變數字串的長度。

例如：

```text
score_num = 99   → 長度 2
score_num = 100  → 長度 3
score_num = 1000 → 長度 4
```

### `-gt`

在 `[ ... ]` 的整數比較中，`-gt` 表示 **greater than**，也就是「大於」。

其他常見整數比較運算子包括：

| 運算子 | 意義 |
|---|---|
| `-eq` | 等於 |
| `-ne` | 不等於 |
| `-lt` | 小於 |
| `-le` | 小於或等於 |
| `-gt` | 大於 |
| `-ge` | 大於或等於 |

這些是整數比較運算子，不是用來比較一般字串的語法。

### `||`

`||` 是邏輯「或」：

```bash
條件一 || 條件二
```

只要其中一個條件成立，整體條件就成立。

因此本段拒絕下列任一情況：

1. 分數字串長度大於 3。
2. 分數數值大於 100。

先檢查長度，可避免把任意長的數字直接拿去做數值比較。因為前面已經確認只包含數字，移除前導零後，超過三位數的非負整數一定大於 `100`。

此處沒有另外檢查小於 `0` 的條件，因為前面的數字驗證已經拒絕了負號。

## 11. 根據成績決定等級和評語

```bash
case "$score_num" in
    100|9[0-9])
        grade="A+"
        comment="EXCELLENT"
        ;;
    8[0-9])
        grade="A"
        comment="VERY GOOD"
        ;;
    7[0-9])
        grade="B"
        comment="GOOD"
        ;;
    6[0-9])
        grade="C"
        comment="PASS"
        ;;
    *)
        grade="F"
        comment="FAIL"
        ;;
esac
```

這裡再次使用 `case`，依分數模式指定兩個變數：

- `grade`：成績等級。
- `comment`：評語。

### 成績模式

#### `100|9[0-9]`

表示以下任一情況：

- 剛好是 `100`。
- 以 `9` 開頭，第二個字元是 `0` 到 `9`，也就是 `90` 到 `99`。

結果：

```bash
grade="A+"
comment="EXCELLENT"
```

#### `8[0-9]`

表示 `80` 到 `89`，結果是 `A` 和 `VERY GOOD`。

#### `7[0-9]`

表示 `70` 到 `79`，結果是 `B` 和 `GOOD`。

#### `6[0-9]`

表示 `60` 到 `69`，結果是 `C` 和 `PASS`。

#### `*`

其餘所有合法分數都會進入預設分支，指定為 `F` 和 `FAIL`。

因為成績已經被限制在 `0` 至 `100`，這裡的 `*` 實際上代表 `0` 至 `59` 的分數。

## 12. 確認程式檔名格式

```bash
expected_name="${id}.sh"
```

這行將學號和字串 `.sh` 接在一起，形成預期檔名。

例如：

```text
id = E12345
expected_name = E12345.sh
```

Shell 會把雙引號中的變數展開，所以：

```bash
"${id}.sh"
```

會先代入 `id` 的值，再接上 `.sh`。

接著比較使用者輸入的檔名：

```bash
if [ "$filename" != "$expected_name" ]; then
    echo "錯誤：程式檔名必須是 $expected_name！"
    exit 1
fi
```

### `!=`

在字串條件比較中，`!=` 表示「不相等」。

因此，若 `filename` 與 `expected_name` 不相同，程式就會顯示錯誤並結束。

例如，若學號是 `E12345`：

- `E12345.sh`：通過。
- `e12345.sh`：不通過，大小寫不同。
- `E12345.SH`：不通過，副檔名大小寫不同。
- `program.sh`：不通過，檔名不符合規定。

## 13. 檢查程式檔案狀態

```bash
if [ ! -e "$filename" ]; then
    echo "錯誤：程式檔案不存在！"
    exit 1
elif [ ! -f "$filename" ]; then
    echo "錯誤：程式檔案不是普通檔案！"
    exit 1
elif [ ! -r "$filename" ]; then
    echo "錯誤：程式檔案不可讀取！"
    exit 1
fi
```

### `elif`

`elif` 是 `else if` 的縮寫。前一個條件不成立時，程式才檢查下一個條件。

此處依序檢查：

1. 檔案或路徑是否存在。
2. 是否為普通檔案。
3. 是否可讀取。

這種順序很有用：如果檔案根本不存在，就先回報「不存在」，不必繼續檢查其他性質。

### `!`

`!` 在條件測試中表示「反轉」條件。

例如：

```bash
[ ! -e "$filename" ]
```

代表「指定路徑不存在」。

### 檔案測試運算子

| 運算子 | 檢查內容 |
|---|---|
| `-e` | 路徑是否存在 |
| `-f` | 是否為普通檔案 |
| `-r` | 目前執行者是否可讀取 |

### 普通檔案與目錄的差異

普通檔案通常是一般資料檔案，例如文字檔或 Shell 腳本。目錄雖然也是檔案系統中的一種項目，但不符合 `-f` 的普通檔案測試。

所以使用者就算輸入的路徑存在，如果它是目錄，也會收到「不是普通檔案」的錯誤訊息。

## 14. 選擇輸出檔名

```bash
out_file="GRADE"
```

先將預設輸出檔名設定為 `GRADE`。

### 如果 `GRADE` 已存在

```bash
if [ -e "$out_file" ]; then
    read -r -p "GRADE 已存在，請輸入新的輸出檔名: " out_file
```

`-e` 用來檢查該路徑是否已存在。若存在，程式便請使用者輸入另一個名稱，並把新輸入存入 `out_file`。

接著檢查第一次輸入的新名稱：

```bash
if [ -z "$out_file" ] || [ "$out_file" = "GRADE" ] || [ -d "$out_file" ]; then
```

這裡使用 `||`，所以三個條件中任何一項成立，都會視為不合法：

- `-z "$out_file"`：名稱是空字串。
- `"$out_file" = "GRADE"`：仍然輸入 `GRADE`。
- `-d "$out_file"`：該名稱已指向一個目錄。

### `=`

在 `[ ... ]` 中，此處的 `=` 用於字串相等比較：

```bash
[ "$out_file" = "GRADE" ]
```

### `-d`

`-d` 用來檢查路徑是否為目錄。

### 最多重問一次

如果第一次輸入不合法，程式會再問一次：

```bash
echo "錯誤：輸出檔名不合法，請再輸入一次。"
read -r -p "請輸入新的輸出檔名: " out_file
```

然後用相同條件再檢查一次：

```bash
if [ -z "$out_file" ] || [ "$out_file" = "GRADE" ] || [ -d "$out_file" ]; then
    echo "錯誤：輸出檔名仍不合法，程式結束。"
    exit 1
fi
```

若第二次仍然不合法，程式便結束。

### 這裡檢查的範圍

程式只排除：

- 空字串。
- `GRADE`。
- 目前已存在且為目錄的路徑。

它沒有檢查其他狀況，例如：

- 新輸出檔名是否是已存在的普通檔案。
- 該檔案是否可寫。
- 父目錄是否存在。
- 檔名是否包含不適合的字元。

因此，後續實際寫入時仍可能失敗。

## 15. 整理輸出內容

```bash
result="
學生學號：$id
學生科系：$dept
數學成績：$score_num
成績等級：$grade
評語：$comment
程式檔名：$filename
"
```

這裡使用雙引號建立多行字串，並將結果放進 `result` 變數。

雙引號內的變數會展開，因此：

```bash
學生學號：$id
```

會變成實際輸入的學號。

這個字串從第一個雙引號後的換行開始，直到結尾的雙引號為止。字串本身包含換行，所以顯示結果會分成多行。

例如，假設：

```text
id       = E12345
dept     = ELECTRICAL ENGINEERING
score_num = 88
grade    = A
comment  = VERY GOOD
filename = E12345.sh
```

`result` 會包含類似內容：

```text
學生學號：E12345
學生科系：ELECTRICAL ENGINEERING
數學成績：88
成績等級：A
評語：VERY GOOD
程式檔名：E12345.sh
```

字串最前面和最後面也各有一個換行。這通常不影響閱讀，但可能讓輸出前後多出空行。

## 16. 同時顯示並寫入檔案

```bash
if printf '%s\n' "$result" | tee -a "$out_file"; then
    echo "資料已儲存至 $out_file"
else
    echo "錯誤：無法寫入輸出檔案！"
    exit 1
fi
```

這段把 `printf` 和 `tee` 接在一起使用。

### `printf`

`printf` 用來按照格式輸出文字。它比某些 `echo` 的使用方式更能明確控制格式。

格式字串：

```bash
'%s\n'
```

表示：

- `%s`：輸出一段字串。
- `\n`：最後輸出換行。

`"$result"` 是要輸出的字串。

### `|` 管線

管線符號 `|` 會把左邊命令的標準輸出，接到右邊命令的標準輸入。

因此：

```bash
printf '%s\n' "$result" | tee -a "$out_file"
```

的資料流是：

```text
result → printf → 管線 → tee → 畫面與輸出檔案
```

### `tee`

`tee` 會將收到的文字同時：

1. 輸出到終端機。
2. 寫入指定檔案。

### `-a`

`-a` 代表 **append**，也就是附加在檔案尾端。

- 檔案不存在：通常會建立新檔案。
- 檔案已存在：將新內容加在後面，不覆蓋原有內容。

若沒有 `-a`，`tee` 預設會覆寫檔案內容。

### `if 命令; then ... else ... fi`

在這種寫法中，`if` 會根據命令的結束狀態判斷成功或失敗：

- 命令成功，執行 `then` 分支。
- 命令失敗，執行 `else` 分支。

所以程式成功輸出後，顯示檔名；若輸出失敗，則顯示錯誤訊息並以狀態碼 `1` 結束。

## 17. 程式中的重要 Shell 符號與語法

| 語法 | 意義 |
|---|---|
| `#` | 在一般程式行中表示註解；在 `${變數#模式}` 中則是參數展開運算子 |
| `$變數` | 取得變數的值 |
| `${...}` | 明確界定變數名稱，或執行參數展開 |
| `"` | 保護字串，並允許變數展開 |
| `'` | 保持字面內容，不展開其中的變數 |
| `;` | 分隔同一行中的命令，例如 `if 條件; then` |
| `&&` | 前一個命令成功後才執行下一個命令 |
| `||` | 前一個命令失敗時，或在條件式中表示「或」 |
| `|` | 將左側命令輸出接到右側命令輸入 |
| `!` | 在條件測試中反轉結果 |
| `*` | 在模式中匹配任意數量的字元 |
| `;;` | 結束 `case` 的一個分支 |
| `fi` | 結束 `if` 結構 |
| `esac` | 結束 `case` 結構 |

同一個符號會依所在語法有不同用途。例如 `#` 在註解開頭和 `${變數#模式}` 中的意義不同。

## 19. 使用時需要留意的行為

### 輸入含空格的檔名

讀取輸入時使用 `read -r`，所以可以讀取包含空格的文字；而在多數檔案檢查與輸出命令中也使用了雙引號，能保護該字串作為單一參數傳入。

但程式檔名必須等於學號加 `.sh`，一般輸入含空格的名稱不會符合規則。

### 科系只接受大寫英文字母

判斷只接受 `E`、`C`、`M`。輸入小寫字母不會自動轉換成大寫。

### 成績會以文字方式先驗證

成績先被確認為非空且只含 `0` 到 `9`，再移除前導零和檢查上限。這樣可以避免小數、負數、符號或英文字母進入分級步驟。

### 輸出內容採附加模式

由於使用 `tee -a`，再次執行並寫入同一個輸出檔時，舊資料會保留，新資料接在後面。

## 20. 總結

這支程式的主要技巧包括：

- 用 `read -r -p` 取得互動式輸入。
- 用 `if` 與 `case` 進行條件判斷。
- 用 `${id:0:1}` 擷取學號第一個字元。
- 用模式 `[!0-9]` 驗證輸入是否含有非數字字元。
- 用 Bash 參數展開移除成績前導零。
- 用整數比較運算子檢查成績範圍。
- 用 `-e`、`-f`、`-r`、`-d` 檢查檔案狀態。
- 用 `printf | tee -a` 同時顯示資料並附加寫入檔案。
- 用 `exit 1` 表示程式因錯誤提前結束。

整體上，程式按照「先驗證輸入，再處理與輸出」的順序設計。每一項必要條件通過後，才會繼續進入下一階段。

## 21. Webminal 執行與邏輯測試

以下步驟以 Webminal 中已儲存的 `grade.sh` 為例。每次執行只處理一位學生；每個測試案例都要重新執行一次腳本。程式檔名使用小寫 `.sh`，例如學號 `E1234567` 對應 `E1234567.sh`。

### 21.1 檢查程式語法

在 Webminal 終端機輸入：

```bash
bash -n grade.sh
```

若沒有任何輸出，表示 Bash 沒有發現語法錯誤。若有錯誤，先修正錯誤再進行下列測試。

### 21.2 建立測試用學生檔案

腳本會檢查學生程式檔是否存在、是否為普通檔案，以及是否可讀。測試檔不需要執行權限。先建立三個科系測試檔：

```bash
printf '#!/bin/bash\necho Student program\n' > E1234567.sh
printf '#!/bin/bash\necho Student program\n' > C1234567.sh
printf '#!/bin/bash\necho Student program\n' > M1234567.sh
```

可用 `ls -l` 確認檔案存在：

```bash
ls -l E1234567.sh C1234567.sh M1234567.sh
```

### 21.3 執行一次合法資料測試

執行：

```bash
bash grade.sh
```

依提示逐項輸入，每一項輸入後按 Enter：

```text
E1234567
92
E1234567.sh
```

預期結果包含：

- 科系：`ELECTRICAL ENGINEERING`
- 成績等級：`A+`
- 評語：`EXCELLENT`
- 輸出檔案：若 `GRADE` 尚不存在，寫入 `GRADE`

若 `GRADE` 已存在，程式會要求另一個輸出檔名。輸入例如 `RESULT1.TXT`。可用以下命令查看結果：

```bash
cat GRADE
```

或查看實際選用的檔案：

```bash
cat RESULT1.TXT
```

### 21.4 測試三種科系分類

每次執行 `bash grade.sh`，測試一位學生，並輸入相符的學號與檔名：

| 學號 | 程式檔名 | 預期科系 |
|---|---|---|
| `E1234567` | `E1234567.sh` | `ELECTRICAL ENGINEERING` |
| `C1234567` | `C1234567.sh` | `COMPUTER SCIENCE` |
| `M1234567` | `M1234567.sh` | `MECHANICAL ENGINEERING` |

若輸入 `X1234567`，預期顯示非法學號訊息並結束。科系判斷只接受大寫 `E`、`C`、`M`。

### 21.5 測試成績分級邊界

以下每個分數都要各自重新執行一次腳本，並使用已建立的相符學號和檔名：

| 測試分數 | 預期等級 | 預期評語 |
|---:|---|---|
| `100`、`90` | `A+` | `EXCELLENT` |
| `89`、`80` | `A` | `VERY GOOD` |
| `79`、`70` | `B` | `GOOD` |
| `69`、`60` | `C` | `PASS` |
| `59`、`0` | `F` | `FAIL` |

這些分數包含各級距的上下邊界，可確認邊界分數被分到正確等級。

### 21.6 測試不合法成績

每次測一項，執行腳本後輸入有效學號，再輸入下列成績之一：

| 輸入 | 預期結果 |
|---|---|
| `101` | 顯示成績範圍錯誤並結束 |
| `-1` | 顯示成績格式錯誤並結束 |
| `abc` | 顯示成績格式錯誤並結束 |
| `85.5` | 顯示成績格式錯誤並結束 |
| 空白後直接按 Enter | 顯示成績格式錯誤並結束 |

### 21.7 測試檔名規則和檔案檢查

使用學號 `E1234567` 時，正確檔名必須是 `E1234567.sh`：


- 輸入 `wrong.sh`：預期顯示檔名不符。
- 輸入 `E1234567.SH`：預期顯示檔名不符，因為本版本要求小寫 `.sh`。
- 輸入正確格式但不存在的名稱，例如學號 `E7654321`、檔名 `E7654321.sh`：預期顯示檔案不存在。

可建立另一個正確測試檔：

```bash
printf '#!/bin/bash\necho Student program\n' > E7654321.sh
```

普通檔案和可讀性可用下列方式檢查：

```bash
test -f E7654321.sh && echo '是普通檔案'
test -r E7654321.sh && echo '檔案可讀'
```

### 21.8 測試輸出檔名的重新輸入

當目前目錄已有 `GRADE` 時，程式會要求輸入另一個輸出檔名。可以分別測試：

1. 輸入空白：預期要求重新輸入一次。
2. 輸入 `GRADE`：預期要求重新輸入一次。
3. 輸入一個已存在的目錄名稱：預期要求重新輸入一次。
4. 第二次仍輸入上述不合法名稱：預期顯示錯誤並結束。
5. 輸入合法名稱，例如 `RESULT2.TXT`：預期完成並將結果附加寫入該檔案。

建立目錄供測試時可輸入：

```bash
mkdir TESTDIR
```

測試完成後若要移除這個空目錄，可輸入：

```bash
rmdir TESTDIR
```

### 21.9 測試時的輸入方式

執行 `bash grade.sh` 後，看到提示時只輸入該欄的值，不要把提示文字一起輸入。例如：

```text
請輸入學生學號: E1234567
請輸入數學成績: 92
請輸入程式檔案名稱: E1234567.sh
```

若終端機沒有清楚顯示提示但游標仍在等待，仍可先輸入一項答案並按 Enter。使用 `bash -x grade.sh` 可顯示執行追蹤，協助確認程式目前停在哪一行；正常測試則使用 `bash grade.sh`。

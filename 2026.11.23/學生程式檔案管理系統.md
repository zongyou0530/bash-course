請撰寫一個 bash shell script，建立一個「學生程式檔案管理系統」。程式執行後，必須使用 select 顯示下列選單：
check file
check department
show grade
save result
exit
使用者每次選擇一個功能後，程式執行對應工作；除非使用者選擇 exit，否則選單應再次出現，讓使用者可以繼續選擇其他功能。
當使用者選擇 check file 時，程式要求輸入一個程式檔案名稱，並依序檢查該檔案是否存在、是否為普通檔案以及是否可讀。若檔案不存在，顯示 file not found；若不是普通檔案，顯示 not a regular file；若不可讀，顯示 not readable；若所有條件皆符合，顯示 file ok。
當使用者選擇 check department 時，程式要求輸入學生學號，並根據學號第一個字母判斷科系。e 代表 electrical engineering，c 代表 computer science，m 代表 mechanical engineering，其他開頭則顯示 invalid student id。此部分必須使用 case statement 完成。
當使用者選擇 show grade 時，程式要求輸入一個 0 到 100 的數學成績。90 到 100 分顯示 a+，80 到 89 分顯示 a，70 到 79 分顯示 b，60 到 69 分顯示 c，低於 60 分顯示 f。若成績小於 0 或大於 100，顯示 invalid score。成績等級必須使用 case statement 判斷。
當使用者選擇 save result 時，程式要求輸入學生學號、數學成績以及程式檔名，並將這三項資料寫入名為 result 的檔案中。如果 result 尚不存在，直接建立；如果已存在，則將新資料加在檔案最後，不可覆蓋原有資料。
當使用者選擇 exit 時，程式顯示 goodbye，然後結束。
若使用者輸入不在選單範圍內的選項，例如 6、0 或其他錯誤輸入，程式必須顯示 invalid selection，然後重新顯示選單。
本題必須使用 select 建立主選單，並搭配 case 判斷使用者選擇的功能。各功能內可使用 if / elif / else、字串比較、數字比較、檔案屬性測試及檔案輸出完成。
不得使用 python、c、awk、sed 或 grep 協助完成。

### **核心語法與關鍵字**

- **Shebang (** **#!/bin/bash** **)**：必須放在腳本第一行，指定 Bash 直譯器
- read 變數名  /  read -p "請輸入xxx: " 變數名：讀取使用者鍵盤輸入。
- **echo -n**：輸出文字且**不自動換行**
- **算術運算**：
    - 舊式 `expr`：`sum=`expr \\(a + \\)b``（數字與符號間**必須有空格**；乘號 `\*` 與括號 `\\(` `\\)` 必須加反斜線跳脫）[4][12]。
    - 擴充語法 `\\((( ))` / `let`：`sum=\\)((a + b))` 或 `let sum=a+b`（不需跳脫符號，語法更直覺）

### **💡 2026.09.14** coding note

**逐行邏輯拆解**：

1. `read length` / `read width`：取得矩形長與寬。
2. `area=`expr $length * $width``：計算面積（ 前需加 `` 避免被視為萬用字元）
3. `perimeter=`expr $ $length + $width $ * 2``：計算周長（括號前需加 `\` 避免被視為 Shell 算術優先權符號）
4. `today=$(date +%Y-%m-%d)`：使用指令替換抓取今日系統日期
5. `echo -n $number1`：印出提示文字，`n` 讓光標留在同格等待輸入
6. `expr $number1 \* 3 / 100`：進行匯率換算。*注意：* *expr* *僅支援整數運算，小數會自動被捨去*

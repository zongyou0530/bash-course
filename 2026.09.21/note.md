### **核心語法與關鍵字**

- **位置參數 (Positional Parameters)**：
    - `$1`, `$2`, `$3`：分別代表命令列傳入的第一、二、三個參數
    - `$#`：傳入參數的**總數量**
    - `$*`：所有參數組成的字串清單
- 數值比較符號（專用於數字，不可用於字串）
    - `eq` (等於)、`ne` (不等於)、`gt` (大於)、`ge` (大於等於)、`lt` (小於)、`le` (小於等於)
- **重導向符號**：
    - `&gt;` (覆寫)：蓋掉目標檔案舊內容
    - `&gt;&gt;` (追加)：將輸出紀錄接在檔案末端

### **💡 2026.09.21** coding note

1. 檢查命令列參數數量

if [ $# -ne 3 ]; then

檢查輸入的參數數量是否不等於 3。若不等於 3，就印出提示文字，並使用 exit 1 結束程式，回傳錯誤狀態碼。

1. 將參數賦值給變數

a=$1
b=$2
c=$3

將命令列輸入的三個參數分別指定給變數 a、b、c。
$1 代表第一個參數，$2 代表第二個參數，$3 代表第三個參數。
注意：等號兩側不能有空格。

1. 冒泡排序（Bubble Sort）

透過暫存變數 temp 交換數值，將三個數字由小到大排列，確保 a ≤ b ≤ c。
排序後，c 就是最長邊。

1. 三角不等式驗證

三角形的最長邊必須小於另外兩邊的和：
c < a + b

若 c ≥ a + b，則無法形成三角形。

1. 畢氏定理判定三角形種類

比較 a² + b² 與 c²：

a² + b² = c²：直角三角形
a² + b² > c²：銳角三角形
a² + b² < c²：鈍角三角形

程式可以使用 sum 儲存 a² + b²，使用 max 儲存 c²，再比較兩者大小。

1. 追加重導向（Append Redirection）

> RESULT
> 

使用 >> 將輸出內容追加到 RESULT 檔案末尾，保留之前的測試紀錄，不會覆蓋原有內容。
